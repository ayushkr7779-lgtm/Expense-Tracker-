# Expense Tracker

A simple web-based Expense Tracker created using HTML, CSS, and JavaScript.

## Features

- Add income transactions
- Add expense transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Delete transactions
- Save data using browser localStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Extract the ZIP file.
2. Open the `expense_tracker` folder in Visual Studio Code.
3. Open `index.html`.
4. Install the Live Server extension in VS Code.
5. Right-click on `index.html`.
6. Click **Open with Live Server**.

You can also directly open `index.html` in any web browser.
